# One CTC acoustic model for all alignment work

**Status (2026-11-19).** The Reading sync card in the reader's More sheet is gone: a rejected rebuild's reason shows on the book's Reading sync page (`#book/<workId>/sync`, #537) and in Activity, which replaced the Activity page. The decision stands.

Sonder generates every alignment map, and scores ebook candidates against the audio, with a single resident Wav2Vec2 Base CTC model (`WAV2VEC2_ASR_BASE_960H`), replacing both Whisper and aeneas. One acoustic pass per recording is cached and reused for locating passages, timing sentences and checking candidates; there is no hidden Whisper fallback. On the labelled sample Base met the 250 ms sentence and transition thresholds, and a chapter took 6.93 s on the WSL GPU against 38.43 s for the full current job. Keeping Whisper only for passage discovery kept almost all of that cost (39.40 s).

## Consequences

- **English only.** Base is trained on English LibriSpeech. A book in another language gets an explicit "language not supported" outcome and stays unsynced; there is no fallback engine.
- **Maps are disposable and always estimated.** Nobody reviews or corrects a map, so there is nothing to preserve or merge. A map made by an older engine generation is rebuilt automatically, and the old map stays served until the rebuild publishes. Amended for #379: the rebuild replaces the old map only when it is not much worse. It is rejected, and the old map kept, when it maps nothing while the old map maps something, when it covers more than 2 points less of the text (`REBUILD_MAX_COVERAGE_DROP`), or when it ends "language not supported" over an old map with intervals. The same rule guards each ebook-set member's projection when a consensus map is rebuilt. A rejected rebuild shows its reason on the Reading sync card and the Activity page and is not queued again automatically; a first map for a pair publishes whatever it covers.
- **Hosts.** The model runs on the WSL GPU. When WSL is unreachable, lisa runs the same engine on CPU. Alignment runs only on these pool hosts: production's N150 runs no alignment worker, and its `sonder-alignment` container was retired with the old engines (#279). A map made on CPU and one made on GPU count as the same engine generation.
- **Retired engines (2026-11-14, #279).** Whisper and aeneas are gone from the worker code, the worker image and the model download, and so is the aeneas rollback switch. Before removal, CTC probing picked the same edition as Whisper for all eight Dungeon Crawler Carl titles ([PR #375](https://github.com/jahnzh/sonder/pull/375)), and the labelled-sample gate passed on the WSL GPU and lisa's CPU without the old engines ([qualification](../CTC_WORKER_POOL.md#qualification-2026-11-14-279)). Maps an older engine made stay readable until their engine-generation rebuild replaces them; a job of a retired engine that becomes active again is planned under CTC before it runs.
- **TorchAudio is pinned to 2.8**, because `forced_align` is removed in 2.9. The path code sits behind one adapter, and replacing the kernel is a follow-up before any upgrade.
